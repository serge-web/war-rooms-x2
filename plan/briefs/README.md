# Work package briefs

Each work package (WP) in [the development plan](../../WRX1-Dev-Plan.md) has a brief here, written before its session starts. A brief lists:

- **SRD ids** the WP delivers;
- **Goal**, in one or two sentences;
- **Acceptance**: the tests or checks that must pass before it merges;
- **Owns**: the folders only this WP may edit while it is active;
- **Consumes**: the frozen interfaces it may use but not change;
- **Notes**: open points and decisions.

Phase 0 and Phase 1 briefs are written. Phase 1 briefs are drafts until Gate G0, and are revised then with the results of WP 0.1–0.3. Briefs for Phases 2 and 3 are written at the start of each phase.
