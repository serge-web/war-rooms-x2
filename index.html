War Rooms X1Chat-based wargames in the browser

Games designed by an admin, played in a dockable chat workspace, with an XMPP server as the only backend.

Background
Architecture
PR index

One backend

All game data lives in a standard XMPP server, ejabberd. There is no app server and no database.

Mock backend for demos

A browser-only mock server stands in for XMPP, so any build can be tried without installing anything.

Runs offline

Every asset is bundled, so the client runs on air-gapped and internal networks.

Built in the open

Every pull request gets a live preview of this site and the app, listed in the PR index.
